# Симуляция плавучести лодки

Корпус задаётся сеткой `data/model.obj`. Сила Архимеда считается по треугольникам и складывается в таблицу. Симуляция движения читает эту таблицу, а не пересчитывает полигоны на каждом шаге.

Запуск из корня проекта:

```bash
.venv/bin/python -m src.main
```

Открывается одно окно параметров. **Запустить** скрывает его и стартует выбранный сценарий. Закрытие окна сценария возвращает то же окно параметров. Крестик окна параметров завершает программу.

## Сценарии

| Сценарий | Что делает |
| --- | --- |
| Симуляция | Движение лодки: Архимед из таблицы, сопротивление, тяга. В конце графики и, если включена анимация, вид сбоку. |
| Предрасчёт | Обход модели по сетке осадок и углов. Пишет `data/buoyancy_table.pkl` и компактный `data/buoyancy_table.npz`. Долго. Прервать: Ctrl+C в терминале. |
| Сетка модели | Один кадр корпуса без таблицы. Красный полигон над водой, синий под водой. Зелёная стрелка — суммарная сила, оранжевая точка — точка приложения, голубая плоскость — уровень воды. |

Отдельные команды, минуя окно: `python -m src.run_simulation`, `python -m src.precompute_table`, `python -m src.run_mesh_view`, `python -m src.lookup_demo`, `python -m src.run_animation`.

## Конфиг

Файл `config/simulation.json`. Окно параметров записывает в него правки. В `src/main.py` словарь `CONFIG_OVERRIDES` может перекрыть поля до открытия окна: ключ `simulation.dt` пишет во вложенный объект, ключ без точки заменяет поле целиком.

| Поле | Смысл |
| --- | --- |
| `model_path` | OBJ-модель корпуса. |
| `buoyancy_table_path` | Таблица плавучести. Рядом читается `.npz`, если он есть. |
| `table_scale` | Множитель координат центра давления при загрузке таблицы. |
| `water_level` | Уровень воды, м. Погружение считается как `water_level - Z`. |
| `fluid_density`, `gravity`, `mass` | Плотность воды, g и масса лодки. |
| `rotation_deg` | Крен `alpha`, дифферент `psi`, рыскание `phi` для просмотра сетки, градусы. |
| `precompute_grid` | Диапазон и шаг осадки, крена и дифферента. За краем сетки интерполяция берёт крайнее значение таблицы. |
| `simulation.t_max`, `dt` | Длительность и шаг интегрирования, с. |
| `simulation.use_equilibrium_z` | Старт на высоте, где Архимед равен весу. Иначе берётся `initial_z`. |
| `simulation.initial_z` | Начальная высота лодки. Меньше нуля — глубже. |
| `simulation.initial_quaternion` | Ориентация `q0, q1, q2, q3`. Без крена: `1, 0, 0, 0`. |
| `simulation.trust_force_body` | Тяга в связанной системе, Н: `Fx, Fy, Fz`. |
| `simulation.animate`, `animation_stride` | Ролик после графиков и шаг по кадрам. |
| `mesh_subdivide` | Сколько раз дробить треугольники в сценарии сетки. `0` — как в OBJ. |

## Файлы

| Путь | За что отвечает |
| --- | --- |
| `src/main.py` | Точка входа: окно, затем выбранный сценарий. |
| `src/visualization/launcher.py` | Окно сценария и полей конфига. |
| `src/run_simulation.py` | Загрузка таблицы, начальное Z, интегрирование RK4, графики. |
| `src/dynamics/boat_dynamics.py` | Уравнения движения: Архимед, сопротивление, тяга, кватернион. |
| `src/precompute_table.py` | Запуск предрасчёта таблицы. |
| `src/forces/buoyancy.py` | Полигон, сила на грань, сборка корпуса, заполнение таблицы. |
| `src/forces/base_force.py` | Общий интерфейс силы: точка приложения и вектор. |
| `src/utils/table_loader.py` | Чтение `.npz` / `.pkl` и квадратичная интерполяция силы и центра давления. |
| `src/utils/config.py` | Чтение и запись `config/simulation.json`, сборка сетки осадка–крен–дифферент. |
| `src/utils/rotations.py` | Поворот вектора кватернионом и обратный поворот. |
| `src/run_mesh_view.py` | Сценарий сетки: поворот, расчёт Архимеда, картинка. |
| `src/visualization/buoyancy_view.py` | 3D-картинка полигонов и суммарной силы. |
| `src/visualization/animation.py` | Графики истории и анимация вида сбоку. |
| `src/lookup_demo.py` | Печать одной точки из таблицы, без динамики. |
| `src/run_animation.py` | Ролик, в котором уровень воды меняется и сила каждый кадр считается по полигонам. |
| `data/model.obj` | Геометрия корпуса. |
| `requirements.txt` | numpy, trimesh, matplotlib, scipy, tqdm. |
